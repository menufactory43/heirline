# Glossaire anglais : les noms propres

La version anglaise d'Heirline garde le ton de la bible (docs/histoire.md) : sobre, un peu sec, avec de l'humour seulement dans les répliques. Un nom garde sa forme française quand il sonne bien en anglais (prénoms, Ossara, Tamagoyle, Rembobine). Sinon on le traduit par le sens, pas mot à mot.

## Habitants

Les prénoms et noms de famille restent tels quels (Ysolde Brasier, Joss Ruelle, Agathe Lin…). Les titres et surnoms se traduisent : Petit Jules → Little Jules, Petite Nour → Little Nour, Gros-Louis → Big Louis, Mère Odile → Mother Odile, Sergent → Sergeant, Garde → Guard, Colon / Colone → Settler.
